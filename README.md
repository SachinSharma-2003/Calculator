# 🧮 Modern Calculator (HTML, CSS, JavaScript)

A stylish and fully functional **modern calculator** built using **HTML, CSS, and JavaScript**.  
It features a glassmorphism design, smooth animations, and supports basic arithmetic operations.

---

## 🚀 Features
- 🎨 **Modern UI Design** (Glassmorphism + gradient background)
- 🔢 Supports **Addition, Subtraction, Multiplication, Division**
- ⌫ **Backspace Functionality**
- 🧹 **Clear Button**
- ✅ Responsive & Interactive Buttons
- ⚡ **Real-time calculation with eval()**

---


## 🖥️ How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/Modern-Calculator.git

2. Open index.html in your browser.

3. Start calculating with the modern UI!
